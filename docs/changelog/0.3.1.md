# v0.3.1 - quieter startup, debug logging

> **Upgrading from 0.3.0:** just replace the jar. Your config, levels and player progress carry over.

- **Quieter startup.** Backrooms used to print 3–4 lines for each of its 12 levels when the server
  started. It now prints a single line listing the levels it loaded. Warnings and errors are
  unchanged.

- **Debug logging for troubleshooting.** The detailed per-level lines are still there when you need
  them. Turn them on with `/backrooms debug on` (needs `backrooms.admin`), or set `debug: true` in
  `config.yml`. The extra lines start with `[debug]` and go to `logs/latest.log`, so you can attach
  that file to a bug report. `/backrooms debug off` turns them off again. Both commands save the
  setting to `config.yml`.
