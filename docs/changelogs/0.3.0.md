# 0.3.0

**Supported servers:** Paper or Purpur **1.21.11** (Java 21), or **26.1, 26.1.1, 26.1.2, 26.2, 26.3** (Java 25).

## Minecraft 26.3 support

- Tested on Paper and Purpur 26.3. The bundled datapack now declares compatibility with 26.3's data format.

## Minimum version is now 1.21.11

Earlier versions were listed as compatible with 1.21–1.21.10, but they never worked there. The bundled datapack uses the dimension and biome format introduced in 1.21.11, and the plugin uses APIs that only exist from 1.21.11. On older servers this either stopped the server from booting ("Failed to load datapacks") or crashed the plugin with `NoClassDefFoundError: org/bukkit/GameRules`.

- On servers older than 1.21.11, the plugin now skips its datapack and disables itself with a clear message, and the server starts normally.
- Older versions are not supported, and no backport is planned.

## Time of day on 26.x

On 26.x, levels with a configured `fixed_time` never had it applied (the log showed "Cannot set time in world without world clock"). Those levels now get their own world clock and day cycle on 26.x, frozen at their configured time:

| Level | Time |
|-------|------|
| 84 The Hedge Maze | 14000 (after sunset) |
| 101 Alpha | 13400 (dusk) |
| 37 The Poolrooms | 6000 (noon) |
| 94 Skyblock | 6000 (noon) |

**Note:** this only applies on 26.x. On 1.21.11 these levels still show no time-of-day lighting. The Hedge Maze and Alpha are now noticeably darker on 26.x than on 1.21.11. The Poolrooms and Skyblock look essentially the same.

## Fixes

- Removed a ~9 second startup stall, and the "Initializing Legacy Material Support… this is a bug!" warning, caused by The Corrupted Chunk's block list.

## Docs

- README: added a requirements note, Level 101 (Alpha) in the levels table, and its entrances from the Library and the Server Room.

## For developers

- `make check-overlay` / `make gen-overlay`: the 26.x datapack overlay (`overlay_26x`) is generated from the level configs by `scripts/gen_overlay_26x.py`. CI fails if it's out of date. Regenerate after changing a level's `fixed_time` or `dimension_type`, or the base dimension type JSONs.
- `make build` now clears `bin/` first, so old jars no longer get copied into the test server.
- CI server tests now cover 26.3.
